# ScrapeFall

A simple JavaFX application that uses the scryfall API and Jsoup(or some other java webscraper) to scrape current card catalog from your local LGS! (or tcg.. idc)

## What do it do yugi?

Pretty much just choose what website you're gonna scrape from, choose the card(s) you wanna check the price of, total price of all cards, etc and go!
The app will automatically scrape the given website (Oasis Games from SLC for now) and give you the price of the card(s)!

Since there are no releases (for now) you're gonna have to run it from your chosen IDE.
